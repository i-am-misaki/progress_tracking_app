# progress_tracking_app
案件ごとの進捗状況を管理するためのWebアプリ
案件ごとのタスク進行状況やステータスを可視化し、管理しやすくすることを目的

## 開発背景
実務の中で、案件ごとの進捗確認や管理に課題を感じる場面があり、学習も兼ねて個人開発を開始

## 使用技術

- Backend: Python / FastAPI
- Frontend: React / TypeScript
- その他: Git / REST API

## 実装済み機能
- ログイン機能
- ユーザー登録
- パスワードリセット
